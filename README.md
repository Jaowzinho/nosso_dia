# Para a Minha Pessoa Favorita ❤️

Este é um projeto especial e romântico, criado para celebrar momentos marcantes e guardar memórias afetivas. Foi desenvolvido como um site estático elegante, com foco em uma experiência acolhedora e responsiva.

## 🌟 Funcionalidades

- **Design Afetivo e Acolhedor:** Paleta de cores em tons orgânicos (vinho, terracota, kraft) com fontes elegantes.
- **Cartinha Fixa:** Uma carta em um envelope decorativo, com texto customizável.
- **Galeria de Nossos Momentos (Polaroids):** Suporte para visualização de fotos em tela cheia (Lightbox) com design de polaroids presas com washi tape.
- **Linha do Tempo (Nossa História):** Diário cronológico destacando momentos marcantes (como a primeira conversa, primeiro beijo, etc).
- **Contador de Tempo:** Um cronômetro em tempo real que calcula exatamente há quantos meses, dias, horas, minutos e segundos vocês estão juntos.
- **Coisas que eu gosto em você:** Cards interativos em grid.
- **A Nossa Música:** Player incorporado (embed) do Spotify reproduzindo a música especial do casal, acompanhado pela letra rolavel da música.
- **Surpresinha Final:** Um botão interativo no rodapé que exibe um modal surpresa e possui um contador de abraços.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Semântico e estruturado.
- **CSS3 (Vanilla):** CSS puro com variáveis nativas, Flexbox/Grid, animações suaves, media queries (Mobile-first) e micro-interações.
- **JavaScript:** Lógica para contador de tempo atualizado em tempo real, manipulação de lightbox para imagens, modal de surpresa e partículas decorativas no background (canvas).
- **Spotify Embed:** Integração nativa de iframe para reprodução de áudio.

## 📁 Estrutura de Arquivos

```
/
├── index.html       # Estrutura principal do site
├── style.css        # Todos os estilos, design system e responsividade
├── script.js        # Lógica de interação, lightbox e contador de tempo
├── assets/          # Pasta contendo imagens e fotos (ex: parque.jpg, etc.)
└── README.md        # Documentação do projeto
```

## 🚀 Como Executar Localmente

Como o projeto é um site estático puro, não é necessário instalar dependências (Node.js, npm, etc).
Basta baixar o projeto e abrir o arquivo `index.html` em qualquer navegador moderno.
